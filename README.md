# Student Attendance Management System

## Introduction
The Student Attendance Management System is a C programming project developed to manage student records, course information, and attendance in an organized way. It provides separate login access for students and teachers, allowing them to perform their respective tasks.

## Programming Language
- C Programming

## Main Features

### 1. Login System
- Separate Student and Teacher Login
- Student login account creation and removal
- Separate dashboards for students and teachers

### 2. Student Management
- Add new student records
- Display all student records
- Search students using Student ID
- Update student information
- Delete student records
- Display student records organized by department and semester

### 3. Course Management
- Add new courses
- Display all courses
- Search courses using Course ID
- Update course information
- Delete courses
- Count total courses
- Organize course records by department and semester

### 4. Attendance Management
- Mark student attendance as Present or Absent
- Search attendance records using Student ID
- View attendance by Course ID and Date
- Display all attendance records by department and semester
- Update attendance records
- Delete attendance records
- Prevent duplicate attendance entries for the same student, course, and date

### 5. Student Attendance Report
- View personal student profile
- View course-wise attendance percentages
- Calculate overall attendance percentage
- Display present and total held classes
- Highlight attendance below the required 75% threshold

## File Handling
The project uses CSV files for storing and managing records.

- Students.csv – Stores student information.
- Courses.csv – Stores course information.
- Attendance.csv – Stores attendance records.
- Login.csv – Stores student login information.
